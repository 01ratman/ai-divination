# AI 算命工具（命理推算）需求文档

> 版本：v1.0
> 技术形态：纯前端 HTML + CSS + JavaScript + Canvas，不接入任何 LLM / 后端，全部为预设文本 + 本地算法推算。

---

## 1. 项目概述

### 1.1 产品定位
一款**本地化、可离线运行**的命理推算工具。用户仅需输入三项基本信息，工具即可基于**八字四柱 / 周易六爻 / 紫微斗数**三种传统命理体系进行推算，并以**分主题、多标签页**的形式输出解读。整体采用**预设文本 + 规则算法 + 权重随机**的组合方式生成结果，保证每次占卜都有一定变化，增加"仪式感"。

### 1.2 核心目标
- 纯前端实现，无需服务器与 API，双击即可运行。
- 结合《周易》等传统典籍，文本有一定文化深度。
- 通过 Canvas 动画营造起卦 / 排盘 / 推演的沉浸式仪式感。
- 输出结果以"事业 / 感情 / 财运 / 健康 / 学业 / 综合"等主题分页展示。

### 1.3 术语约定
| 术语 | 说明 |
| --- | --- |
| 四柱八字 | 年、月、日、时四柱干支，共八个字 |
| 起卦 | 六爻占卜中生成卦象的过程 |
| 排盘 | 紫微斗数中建立命盘的步骤 |
| 预设文本 | 开发者预先编写的解读文案（数据字典） |
| 权重随机 | 在多个候选文本中按权重概率选取 |

## 2. 用户角色与使用流程

### 2.1 目标用户
- 对传统命理 / 周易文化感兴趣的普通用户。
- 追求娱乐性与仪式感，不追求专业精确的占卜人群。

### 2.2 用户操作流程
```
进入首页
  │
  ├─ 输入"所在地区"（用于确定时区 / 真太阳时，可留空）
  ├─ 输入"出生年月日"（下拉框选择：年 / 月 / 日）
  ├─ 输入"出生时间"（下拉框选择：时 + 分，可选"不记得"）
  │
  └─ 点击【开始占卜】
        │
        ▼
   Canvas 推演动画（起卦 / 排盘，数秒）
        │
        ▼
   结果页（多标签页展示各命理体系与主题解读）
        │
        └─ 提供【重新占卜】【换一种算法】操作
```

## 3. 功能需求

### 3.1 信息录入模块（首页表单）

#### 3.1.1 所在地区（出生地）
- 下拉框 / 可搜索输入，覆盖中国主要城市及行政区。
- 双重用途：
  1. **真太阳时**：根据经度与时区校正出生时辰。
  2. **方位属性**：判断出生地属**南方 / 北方 / 东方 / 西方 / 中部**，用于五行方位与地域秉性的预设文本维度。
- 允许为空：为空则默认按北京时间（UTC+8）处理，且方位记为"未知"（不参与文本加权或按"中原"处理）。

#### 3.1.2 出生日期
- 三个联动下拉框：**年**（如 1940–2026）、**月**（1–12）、**日**（1–31）。
- 依据所选的年 / 月**自动计算该月天数**（含闰年 2 月 29 日），动态调整"日"的范围。
- 必填。

#### 3.1.3 出生时间
- 两个下拉框：**时**（0–23，或子–亥十二时辰）、**分**（0–59，可按 5 分钟粒度）。
- 提供特殊选项：**"不记得"**。
- 当选择"不记得"时：
  - 时辰记为"未知"，系统采用**三档随机**或**默认正午**规则处理（见 4.1.3），并在结果中明确提示"出生时间未知，结果仅供参考"。

#### 3.1.4 性别
- 必填字段，下拉框选择：**男 / 女**。
- 用途：参与**紫微斗数**大限顺逆排盘；同时用于预设文本的性别维度（男命 / 女命用词差异）。

#### 3.1.5 表单校验
- 必填项缺失时给出友好提示（红色描边 + 顶部 Toast）。
- 年月日合法性联动校验。
- 提交前可"重置"。

### 3.2 占卜触发与动画模块

#### 3.2.1 开始占卜
- 点击按钮后进入全屏遮罩的 **Canvas 动画**。

#### 3.2.2 动画内容（按所选命理体系）
- **八字四柱**：四柱天干地支逐柱"写入"动画，配五行相生相克连线。
- **周易六爻**：模拟"摇铜钱"（三枚铜钱 × 6 次）生成六爻，逐爻点亮，最终形成卦象。
- **紫微斗数**：十二宫位圆盘 / 方盘依次排入主星、辅星的动画。
- 动画时长建议 3–6 秒，提供"跳过动画"按钮。
- 动画结束时播放轻微震动 / 音效（可选），并淡出进入结果页。

### 3.3 结果展示模块（多标签页）

结果页顶部为标签栏，可切换：

| 标签 | 内容 |
| --- | --- |
| 综合概览 | 命盘基本信息 + 总体断语（一句话总结） |
| 八字四柱 | 四柱排盘表 + 五行分布 + 喜用神 + 十神分析 |
| 周易六爻 | 卦名 / 卦辞 / 变卦 + 六爻详解 |
| 紫微斗数 | 命盘十二宫 + 主星分布 + 命主解析 |
| 主题运势 | 事业 / 感情 / 财运 / 健康 / 学业 分主题解读 |
| 典籍原文 | 对应《周易》卦辞、爻辞原文（附白话译注） |

#### 3.3.1 各标签页内容要求
- **综合概览**：姓名（可选）占位、出生信息回显、命盘核心结论（1 句话 + 一段长文）。
- **八字四柱**：
  - 四柱干支表（年柱 / 月柱 / 日柱 / 时柱）。
  - 五行统计（金木水火土数量）与五行占比可视化（Canvas 或 CSS 环形图）。
  - 喜用神 / 忌神判断（基于日主强弱与季节旺衰）。
  - 十神（正官、偏财、食神……）列表。
- **周易六爻**：
  - 本卦 / 变卦的卦名、上下卦、六爻阴阳展示。
  - 卦辞、彖辞、象辞引用。
  - 六爻逐爻解读（结合用神、世应）。
- **紫微斗数**：
  - 十二宫（命宫、兄弟、夫妻、子女、财帛……）排布。
  - 各宫主星、辅星、煞星列表。
  - 命宫主星特性解读。
- **主题运势**：同一命盘下按事业 / 感情 / 财运 / 健康 / 学业输出五段解读。
- **典籍原文**：周易原文与白话对照，附出处。

#### 3.3.2 结果操作
- 【重新占卜】回到首页，保留用户已填信息。
- 【换一种算法】在不重新输入的情况下重新生成另一种命理体系的解读。
- 每个命盘结果生成唯一"卦象/盘面 ID"，用于记录本次结果。

### 3.4 数据与文本组织（核心）

#### 3.4.1 结构化数据字典
以 JS 对象 / JSON 维护：
- **天干 / 地支 / 五行 / 阴阳**表。
- **六十甲子**循环表。
- **节气**数据（用于月柱划分，含公历日期）。
- **周易 64 卦**：卦名、上下卦、卦辞、爻辞（6 爻）、彖辞、象辞、白话译注。
- **紫微 14 主星 + 辅星/煞星**：特性关键词、吉凶属性、组合关系。
- **十神 / 神煞**定义表。

#### 3.4.2 分主题模板
- 每个主题（事业 / 感情 / 财运 / 健康 / 学业）维护多个**预设解读段落模板**。
- 模板包含**插槽变量**，如 `{日主五行}`、`{喜用神}`、`{本卦名}`、`{命宫主星}`，由算法填充。

#### 3.4.3 随机 + 权重组合
- 同一命盘下，从主题模板候选集中**按权重随机选取**组合，保证不同次占卜文本略有差异。
- 权重字段（`weight`）控制选中概率。
- 每个命盘结果整体拼接为一段连贯长文（引言 + 各主题段 + 结语）。

## 4. 核心算法需求（推算逻辑）

> 本节为技术可行性说明，需在实现阶段用 JS 落地。

### 4.1 八字四柱

#### 4.1.1 输入
出生公历年月日时（真太阳时校正后）。

#### 4.1.2 排柱
- **年柱**：以立春为界划分年份干支（立春前属上一干支年）。
- **月柱**：以节气为界，配合年干确定月干（五虎遁）。
- **日柱**：需计算从已知基准日（如 1900-01-01）到出生日的天数，对 60 取模得日干支。
- **时柱**：以日干配时辰（五鼠遁）。时辰由出生时间换算（23–01 为子时等）。

#### 4.1.3 时间未知处理
- 若"出生时间"为不记得：默认按**正午（午时）**或**随机时辰**处理。
- 结果页必须提示"时辰未知，四柱中时柱为假设值"。

#### 4.1.4 五行喜忌
- 统计四柱天干地支五行分布。
- 依据**日主**（日干）与**月令旺衰**判断身强 / 身弱。
- 推导喜用神 / 忌神，并生成五行占比图。

### 4.2 周易六爻

#### 4.2.1 起卦
- 采用"三枚铜钱摇卦法"：每爻三枚铜钱，根据正反面得老阴 / 老阳 / 少阴 / 少阳，六次得六爻（自下而上）。
- 可用**随机数**模拟，或用用户输入信息做**种子**（生日四柱）生成可复现卦象。

#### 4.2.2 卦象解读
- 由六爻得本卦、变卦。
- 结合世应、用神确定解读重点。
- 引用对应卦辞、爻辞与白话译注。

### 4.3 紫微斗数

#### 4.3.1 排盘
- 依据出生年月日时（真太阳时）定命宫、身宫、十二宫。
- 依五虎遁诀定十二宫天干。
- 安十四主星、辅星（左辅右弼、文昌文曲等）、煞星（擎羊陀罗等）。
- 需输入：出生年月日时 + 性别（男 / 女，用于大限顺逆）。

> **注意**：紫微斗数传统上需要**性别**输入。需求中可补充一个可选的"性别"字段（仅在选用紫微斗数时提示），或默认按性别未知处理并提示。

#### 4.3.2 解读
- 命宫主星特性解读。
- 各宫主星组合吉凶判断。
- 生成各宫解读文本。

## 5. 非功能需求

### 5.1 技术架构
- 纯前端：`index.html` + `style.css` + 若干 `js` 模块 + Canvas。
- 数据字典以独立 JS/JSON 文件维护，便于扩展。
- 无需构建工具即可运行；可选配简单本地服务器（如 `npx serve`）。

### 5.2 兼容性
- 支持现代浏览器（Chrome / Edge / Firefox / Safari）。
- 移动端适配（响应式布局，标签页可横向滑动）。

### 5.3 性能
- 页面加载与占卜计算应在 1 秒内完成（数据为本地，无网络请求）。
- Canvas 动画保证 60fps 流畅。

### 5.4 数据与隐私
- 全部本地计算，**不上传任何用户数据**，符合隐私预期。
- 页面可提示"数据仅在本机计算，不会上传"。

### 5.5 文案与合规
- 页面底部添加免责声明："本工具仅供娱乐参考，不构成任何决策依据。"
- 文案结合《周易》等典籍，但避免绝对化、宿命论导向的诱导性表述。

## 7. 页面原型（文字描述）

### 7.1 首页
- 居中标题（如"天机 · AI 命理推演"）。
- 三个/四个输入区块：所在地区、出生日期（三联动下拉）、出生时间（两下拉 + 不记得）、可选性别。
- 底部主按钮【开始占卜】（大、有渐变与悬停效果）。

### 7.2 动画页
- 全屏 Canvas，暗色星空 / 太极 / 卦象氛围背景。
- 动画主体（铜钱摇卦 / 四柱写入 / 星盘展开）。
- 顶部进度或跳过按钮。

### 7.3 结果页
- 顶部：命盘 ID、出生信息回显、综合一句话结论。
- 标签栏：综合 / 八字 / 六爻 / 紫微 / 主题 / 原文。
- 内容区随标签切换，含可视化（五行环图、卦象图、十二宫图，均可由 Canvas 绘制）。
- 底部：重新占卜 / 换一种算法 / 免责声明。

## 9. 已确认决策

1. **需要性别字段**：必填，参与紫微斗数排盘与文本性别维度。
2. **出生地双重用途**：既用于真太阳时校正，也用于判断**南 / 北 / 东 / 西**方位并参与文本生成。
3. **不保留姓名**：不设姓名输入框。
4. **六爻随机，八字确定**：周易六爻起卦每次**随机**；而八字四柱（及由八字推导的对应卦象）**确定**——一个八字对应一个固定卦象，不随机。

> 说明：六爻标签页既展示随机摇卦结果，也展示由八字确定性推导出的"本命卦"（一个八字对应一个卦）。两者并存，随机性仅作用于摇卦。
