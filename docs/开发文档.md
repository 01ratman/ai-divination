# AI 算命工具 · 开发文档

> 版本：v1.0
> 技术：纯前端 HTML + CSS + JS + Canvas，无后端、无 LLM，全部本地推算 + 预设文本。
> 前置文档：见 `需求文档.md`。

---

## 1. 页面流程总览

用户操作共分 **4 个页面 / 阶段**：

```
┌─────────────┐   点击"开始算卦"   ┌─────────────┐   填写并提交   ┌─────────────┐   推演完成   ┌─────────────┐
│   ① 开始页    │ ───────────────▶ │  ② 信息填写页  │ ───────────▶ │ ③ Canvas 推演 │ ──────────▶ │  ④ 卦象解读  │
│  (start)     │                  │   (form)      │              │  (animate)   │             │  (result)    │
└─────────────┘                  └─────────────┘              └─────────────┘             └─────────────┘
```

页面切换采用 **SPA 单页模式**：所有页面共用一个 `index.html`，通过 JS 显示 / 隐藏各个 `section` 容器，不刷新页面。

### 页面容器与 ID 约定
| 页面 | 容器 id | 说明 |
| --- | --- | --- |
| 开始页 | `#page-start` | 品牌标题 + 开始按钮 |
| 信息填写页 | `#page-form` | 表单输入 |
| 推演动画页 | `#page-animate` | Canvas 全屏遮罩 |
| 结果页 | `#page-result` | 多标签解读 |

## 2. ① 开始页（page-start）

### 2.1 布局
- 居中主标题（如"天机 · 命理推演"）。
- 一句副标题 / 标语（如"参易理，观人生"）。
- 一个主按钮【开始算卦】。
- 底部免责声明："本工具仅供娱乐参考，不构成任何决策依据。"

### 2.2 交互
- 点击【开始算卦】→ `showPage('page-form')` 切到信息填写页。
- 该页无其他前置条件，直接进入表单。

---

## 3. ② 信息填写页（page-form）

### 3.1 表单项
| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 所在地区 | 下拉框 + 可搜索 | 否 | 用于真太阳时校正 + 方位判定 |
| 出生日期 | 年 / 月 / 日 三个联动下拉 | 是 | 日选项随年月的天数动态变化 |
| 出生时间 | 时 / 分 下拉，含"不记得" | 是（可选不记得） | 用于排时柱与时辰文本 |
| 性别 | 下拉（男 / 女） | 是 | 用于紫微排盘 + 文本性别维度 |

### 3.2 表单联动与校验
- **年月日联动**：选择年月后，依据该月天数刷新"日"下拉（含闰年 2 月 29 日）。
- **出生时间"不记得"**：选中后禁用时分下拉，标记为 `unknown`。
- **校验**：必填项为空时红色描边 + Toast 提示；合法后按钮可用。

### 3.3 表单数据对象
提交时组装为统一输入对象（供推算与文本引擎使用）：

```js
const formData = {
  region: { key: "北京", lon: 116.41, lat: 39.90, direction: "east/north" },
  date: { year: 1995, month: 6, day: 15 },
  time: { hour: 10, minute: 30, known: true },   // known=false 表示不记得
  gender: "male",                                  // 'male' | 'female'
};
```

### 3.4 交互
- 点击【开始占卜】→ 组装 `formData` → 校验通过 → `showPage('page-animate')` 进入推演。

## 4. ③ Canvas 推演页（page-animate）

### 4.1 功能
- 全屏遮罩 Canvas，营造仪式感动画。
- 默认推演内容为**六爻摇卦**（最具仪式感），可扩展八字 / 紫微动画。
- 动画完成后自动跳转结果页。

### 4.2 摇卦动画流程（核心）
```
1. 清屏，绘制八卦/太极背景
2. 循环 6 次（自下而上，i=0..5）：
   a. 绘制三枚铜钱，随机翻转（正=字/背=花）
   b. 依据正反组合判定本爻：老阴/老阳/少阴/少阳
   c. 将本爻画入卦位，逐爻点亮
3. 汇总 6 爻 → 得本卦 + 变卦
4. 显示卦名 → 淡出 → 进入结果页
```

### 4.3 爻性判定（三枚铜钱）
| 组合 | 爻性 | 符号 | 是否变爻 |
| --- | --- | --- | --- |
| 3 背 | 老阳 | 阳○ | 变 |
| 2 背 1 字 | 少阳 | 阳 | 否 |
| 1 背 2 字 | 少阴 | 阴 | 否 |
| 3 字 | 老阴 | 阴× | 变 |

### 4.4 随机与确定
- **摇卦结果**：随机（每次不同）。
- **本命卦**：由八字确定性推导（一个八字 → 一个卦），不随机。
- 两者都在结果页展示。

### 4.5 其他
- 提供【跳过动画】按钮（直接生成结果）。
- 动画时长建议 3–6 秒，60fps。

## 5. ④ 卦象解读页（page-result）

### 5.1 布局
- **顶部**：命盘 ID、出生信息回显、一句话总结。
- **标签栏**（横向 Tab）：综合 / 八字 / 六爻 / 紫微 / 主题 / 原文。
- **内容区**：随标签切换。
- **底部操作**：重新占卜 / 换一种算法 / 免责声明。

### 5.2 各标签内容与渲染
| 标签 | 内容 | 渲染方式 |
| --- | --- | --- |
| 综合概览 | 一句话结论 + 长文概述 | 文本 + 五行环图(Canvas) |
| 八字四柱 | 四柱干支表 + 五行统计 + 喜用神 | HTML 表格 + CSS 环形图 |
| 周易六爻 | 本卦/变卦 + 卦辞 + 爻辞 + 断语 | 文本 + 卦象图(Canvas) |
| 紫微斗数 | 十二宫 + 主星 + 命主解析 | 文本 + 星盘图(Canvas) |
| 主题运势 | 事业/感情/财运/健康/学业五段 | 文本卡片 |
| 典籍原文 | 周易原文 + 白话对照 | 文本 |

### 5.3 结果数据结构
推算与文本生成后组装为统一结果对象，交由 `render.js` 渲染：

```js
const result = {
  id: "20260906-XXXX",          // 命盘 ID
  form: formData,               // 原始输入
  bazi: { pillars: [...], fiveElements: {...}, yongshen: "喜木", jishen: "忌金", shishen: [...] },
  liuyao: { benGua: {...}, bianGua: {...}, yaoci: [...] },   // 摇卦结果
  benmingGua: {...},            // 八字推导的本命卦（确定）
  ziwei: { palaces: [...], mainStar: {...} },                // 紫微（可选）
  topics: { career, love, wealth, health, study },           // 主题文本
  summary: "一句话总结",
  closing: "结语",
};
```

### 5.4 操作
- 【重新占卜】→ 回到 `page-form`（保留已填信息）。
- 【换一种算法】→ 保留输入，仅重摇六爻（重新进入动画或直接换卦）。

| 文件 | 职责 |

| `js/main.js` | SPA 页面切换（`showPage`）、初始化 |
| `js/form.js` | 表单联动、校验、组装 `formData` |
| `js/solar.js` | 真太阳时、时辰换算、方位判定 |
| `js/bazi.js` | 八字排盘 + 五行喜忌 |
| `js/liuyao.js` | 六爻摇卦 + 卦象解析 |
| `js/ziwei.js` | 紫微排盘（可选） |
| `js/textEngine.js` | 插槽填充 + 权重随机组合，生成 `result.texts` |

| `js/canvas.js` | 推演动画 + 各可视化图 |
| `data/*.js` | 预设文本与命理数据字典 |

### 页面切换核心函数（main.js）
```js
function showPage(name) {
  // 隐藏所有 section，显示指定 section
  document.querySelectorAll('section.page').forEach(s => s.classList.add('hidden'));
  document.getElementById('page-' + name).classList.remove('hidden');
  window.scrollTo(0, 0);
}
```

## 7. 文本生成流程（textEngine）

```
formData
  └─▶ bazi 推算 → 日主 / 五行 / 喜用神
  └─▶ solar 校正 → 时辰 / 方位
  └─▶ liuyao / benming → 本卦 / 变卦
       │
       ▼
   组装插槽变量：{性别} {日主} {喜用神} {方位} {时辰} {本命卦} {卦辞} ...
       │
       ▼
   从 TOPIC_TEMPLATES 各主题按 weight 随机选 1 段
       │
       ▼
   填充插槽 → 拼接 综合段 + 各主题段 + 结语 → result.texts
```

## 9. 本命卦推导（一个八字 → 一个卦）

为实现"一个八字对应一种卦、且确定不随机"，提供一种可行的**确定性映射**方案（可自行调整）：

1. 由四柱八字得 **8 个字**（年干、年支、月干、月支、日干、日支、时干、时支）。
2. 将每个字（干支）映射到二进制位：天干按五行 + 阴阳编码，地支按五行编码。
3. 依据编码序列，以 **下卦取前三柱、上卦取后三柱**（或按天干地支奇偶），映射为 6 爻。
4. 6 爻组成一个六十四卦序号 → 查 `ZHOUYI` 得本命卦。

> 实现细节（取位 / 映射规则）需在 `liuyao.js` 或独立 `benming.js` 中定义并保持一致，确保同一八字永远得到同一卦。
